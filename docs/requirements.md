# Requirements

## Goal
A personal portfolio that helps recruiters and clients quickly see who Jean Kevin D is, what he has built, and how to contact him.

## Users
- **Recruiters and HR**: skim skills, projects and certificates in under a minute.
- **Interviewers / developers**: open projects, case studies, live sites and code.
- **Clients**: see real work and get in touch on WhatsApp or email.

## Features
- Hero with name, role and a 3D animated block background (Three.js).
- About, quick facts and strengths.
- Skills grouped by type, with "used in" links to projects.
- Project cards: screenshots (desktop + phone), tech stack, features, links, case study.
- Case study page for Brainy Blooms Work Tracker.
- "Next project" teaser.
- Education, leadership and activities.
- Certificates with a full-size viewer and verification links.
- Contact: email, WhatsApp, LinkedIn, GitHub, resume download.
- Night mode, works on phones, keyboard accessible, respects "reduce motion".

## Out of scope
- No login, no database, no admin panel.
- No paid services (the site must stay free to run).
- No blog or CMS for now.

## Quality rules
- Must load on a phone over mobile data. No single file over 2 MB.
- No secrets in the code.
- Every change goes through a pull request with green checks.
